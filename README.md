# ecoFriendWEB

EcoFriend is a PWA about recycling: scan waste, earn points, and track your eco progress.

## Features

- Registration and login
- Camera waste scanning + barcode scanning
- Points, levels, streaks, and recent activity
- Leaderboard and monthly challenges
- Promo code redemption
- PWA support (installable app + service worker)

## Stack

- HTML, CSS, JavaScript modules
- Firebase (Auth + Firestore)
- PWA manifest + service worker
